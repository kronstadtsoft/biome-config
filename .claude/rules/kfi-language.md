# Language

Use clear language appropriate to the reader and the document's purpose.
Prefer active voice, familiar words and consistent terms. Keep instructions direct.
Split long sentences when it improves comprehension; there is no mechanical word-count limit.
Technical terms, Romanian customer copy and quoted source text are appropriate where needed.

Comments explain constraints or reasoning the code cannot make clear. Use the space needed to explain a significant constraint accurately.
Documentation may explain purpose, architecture, tradeoffs, evidence, findings or operating steps.
Remove repeated claims, ceremonial language and unsupported assurances. Preserve reasoning that helps the next reader make a decision.
Do not claim ASD-STE100 conformance without a specific requirement and an actual conformance check.
